Project Description

High-Frequency Telemetry & Intelligent Transit Dispatching

Ohmnibus provides municipal transit authorities and private logistics fleets with real-time positional visibility and automated scheduling intelligence. We developed an interactive Mapbox GL dashboard that plots 450+ concurrent vehicle trajectories without UI stutter or memory leaks.

Using bi-directional WebSockets and lightweight MQTT protocols, dispatchers receive instantaneous traffic congestion reroutes, vehicle battery/fuel metrics, and driver duty-cycle notifications directly inside a streamlined Apple-inspired command interface.
