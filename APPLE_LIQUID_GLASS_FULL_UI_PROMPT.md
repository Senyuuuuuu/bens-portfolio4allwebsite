### Core Physical Laws of Apple Liquid Glassmorphism

1. **Dual-Layer Optical Refraction & Chromatic Saturation Boost**:
   - Transparent glass placed over high-contrast content or dot/grid patterns requires deep Gaussian diffusion paired with chromatic saturation amplification to prevent washed-out, muddy backgrounds:
     ```css
     background: rgba(255, 255, 255, 0.78);
     backdrop-filter: blur(32px) saturate(210%) contrast(104%) brightness(103%);
     -webkit-backdrop-filter: blur(32px) saturate(210%) contrast(104%) brightness(103%);
     ```

2. **4-Tier Specular Chamfered Rim Lighting**:
   - Authentic visionOS glass catches directional ambient light along its top and outer chamfered edges:
     ```css
     border: 1px solid rgba(255, 255, 255, 0.88);
     box-shadow: 
       inset 0 1.5px 1.5px 0 rgba(255, 255, 255, 1),
       inset 0 -1px 1px 0 rgba(0, 0, 0, 0.03),
       inset 0 0 0 1px rgba(255, 255, 255, 0.5),
       0 20px 48px -10px rgba(0, 0, 0, 0.08),
       0 2px 8px rgba(0, 0, 0, 0.02);
     ```

3. **Concentric Geometric Nesting Law**:
   - Outer Container / Card: `border-radius: 24px–30px;`
   - Inner Media / Canvas Trays: `border-radius: 18px–20px;`
   - Concentric Badges & Micro-Pills: `border-radius: 9999px;` (Pill geometry).
   - Software Squircles: `border-radius: 16px–18px;`.

4. **Two-Tier Material Substrates**:
   - **Pearl Liquid Glass (Light)**: For cards, panels, inputs, bento blocks, and floating navigation pills (`rgba(255, 255, 255, 0.78)`).
   - **Obsidian Liquid Glass (Dark)**: For 4K cinema preview frames, code terminals, brand avatars, and footer substrates (`rgba(11, 11, 14, 0.88)` with `inset 0 1.5px 1px 0 rgba(255, 255, 255, 0.22)`).

5. **Tactile Spring Micro-Interactions**:
   - **Hover Glide**: `transform: translateY(-6px) scale(1.008);` with Apple deceleration `cubic-bezier(0.16, 1, 0.3, 1)`.
   - **Active Press**: `transform: scale(0.955) translateY(1.5px);` with rapid spring recoil `cubic-bezier(0.1, 0.9, 0.2, 1)`.
```
