## 2. Core Visual & Design Engineering Directives

### 💎 Apple Glassmorphism & Liquid Specular Materials
- **Dual-Layer Light Refraction**: All floating capsules, interactive toolbars, and dynamic islands MUST use authentic optical refraction:
  ```css
  backdrop-filter: blur(28px) saturate(190%) contrast(102%);
  -webkit-backdrop-filter: blur(28px) saturate(190%) contrast(102%);
  ```
- **Chamfered Specular Rim Lighting**:
  - Light mode surfaces: `inset 0 1px 1px 0 rgba(255, 255, 255, 0.6), inset 0 0 0 1px rgba(255, 255, 255, 0.18)`
  - Dark obsidian surfaces: `inset 0 1px 0 0 rgba(255, 255, 255, 0.22), inset 0 0 0 1px rgba(255, 255, 255, 0.08)`
- **Concentric Geometry**: Outer container border radii MUST mathematically exceed inner element radii by the exact padding offset (`outer_radius = inner_radius + padding_offset`).
- **Tactile Micro-Interactions**:
  - `scale(0.96)` active press haptic response on all buttons, tabs, chips, and pills.
  - Web Audio API synthesized crisp clicks (`playTactileClick()`) on interactive actions with an audio toggle in the navigation.
